# Gonçalo Antão — Portfólio Web 💻

Portfólio pessoal de desenvolvimento web, criado para apresentar projetos de websites modernos e responsivos direcionados a pequenos negócios.

## 🌐 Demo

[Adiciona aqui o link final do teu portfólio no Netlify.](https://goncalo-antao.netlify.app)

## 👨‍💻 Sobre

Sou estudante de Engenharia Informática e desenvolvo websites modernos, responsivos e focados em pequenos negócios.

O objetivo é criar soluções simples, profissionais e funcionais que ajudem empresas e profissionais a melhorar a sua presença online e a facilitar o contacto com clientes.

## ✨ O que inclui

- Apresentação pessoal
- Serviços de desenvolvimento web
- Portfólio de projetos
- Processo de desenvolvimento
- Formulário de contacto
- Contacto através do WhatsApp
- Design responsivo
- Versão adaptada a computador, tablet e telemóvel
- Navegação suave entre secções

## 📂 Projetos apresentados

### Barbearia Prime
Website demonstrativo para barbearia, com serviços, contactos e marcação através do WhatsApp.

### Casa Nostra
Website demonstrativo para restaurante italiano, com menu, horários, contactos e reservas através do WhatsApp.

### IRONLAB Fitness
Website demonstrativo para ginásio, com serviços, planos, equipa e pedido de aula experimental.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub
- Netlify

## 📱 Responsivo

O portfólio foi desenvolvido para funcionar corretamente em diferentes tamanhos de ecrã, incluindo computador, tablet e smartphone.

## 🎯 Objetivo

Este portfólio foi criado para apresentar os meus projetos, demonstrar as minhas capacidades em desenvolvimento web e servir como ponto de contacto para potenciais clientes interessados em criar um website para o seu negócio.
